# Generative UI

Generative UI, model yanıtını yalnızca metin olarak bırakmak yerine göreve uygun etkileşimli bir yüzeye dönüştürür. Tarif, karşılaştırma, plan, araştırma özeti ve kontrol listesi gibi sonuçlar kendi yapılarına sahip olabilir.

İyi bir Generative UI çıktısı; kaynağını, düzenlenebilir alanlarını, tamamlanma durumunu, dışa aktarma seçeneğini ve kullanıcı onayını görünür tutar.
