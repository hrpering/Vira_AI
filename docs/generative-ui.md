# Generative UI

Generative UI turns a model response into a task-specific product surface instead of leaving the result as a paragraph in chat. It can support work such as planning, comparison, research, and review.

A useful Generative UI result should make the appropriate level of context and user control clear. The exact renderer, payload, state, actions, confirmation flow, and output behavior are hosted-product details and are not published here. See the intentionally high-level boundary in [`specs/generative-ui.md`](../specs/generative-ui.md).
