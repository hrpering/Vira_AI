# Model routing

Routing, bir görevi uygun model veya inference yüzeyine yönlendirme kararıdır. Karar; görev türü, dil, bağlam, maliyet, gecikme, kapasite ve politika sınırlarıyla açıklanabilir olmalıdır.

Otomatik routing, kullanıcı kontrolünü ortadan kaldırmaz. Seçilen model, fallback koşulu ve veri sınırı mümkün olduğunda gösterilmelidir.
