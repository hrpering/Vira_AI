# Terminology

- **Model:** A trained system that generates or transforms an output.
- **Open-source model:** A model artifact whose exact code, weights, and terms must be verified at the upstream source.
- **Open-weight:** A model release that publishes weights under its own terms; this is not automatically the same as OSI-approved open-source software.
- **Project:** Reusable task logic or a third-party open-source AI project.
- **Studio:** A product surface for using a repeatable project or task.
- **Generative UI:** Turning a structured response into a task-specific interactive surface.
- **Routing:** Connecting a task with a suitable available AI capability or serving surface.
- **Serving surface:** A place where an AI capability can be made available to a product experience.
- **Output:** A useful result produced through a Vira product surface.
- **Portable AI context:** Useful work context that can be preserved or reused where the product supports it.
- **Availability:** A runtime/account fact; ecosystem presence does not prove availability in Vira.
