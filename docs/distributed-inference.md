# Distributed inference

Dağıtık inference, model çalıştırma kapasitesinin birden fazla node veya serving yüzeyine yayılmasıdır. Bu yaklaşım esneklik sağlayabilir; ancak sağlık, kapasite, routing, güvenlik, gözlemlenebilirlik ve veri yerleşimi açıkça yönetilmelidir.

Dağıtık olmak otomatik olarak daha doğru sonuç anlamına gelmez. Kullanıcıya gecikme, fallback ve çalışma konumu hakkında uygun düzeyde bilgi verilmelidir.
